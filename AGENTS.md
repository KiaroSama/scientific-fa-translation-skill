# Skills

This repository is a Cursor personal-skills tree. Each skill is a
top-level folder (`<name>/SKILL.md`). Clone it as `~/.cursor/skills`.

When the user wants to translate a paper, article, book, or technical
document into scientific Persian — or asks for RTL, چاپ, or a PDF —
read and follow `scientific-fa-translation/SKILL.md` before producing
output. Do this even if `/scientific-fa-translation` is missing from
the slash menu.

Do not use that skill for coding, commits, UI copy, or casual chat.
